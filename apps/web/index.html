Eigenbeleg für Blockchain-Zahlungen

Ein Eigenbeleg ist ein Beleg, den Sie selbst für Ihre eigenen Zahlungen ausstellen, wenn niemand eine Rechnung schickt: Netzwerkgebühren, Storage-Deposits, Zahlungen an Peer-to-Peer-Netzwerke. Er ist keine Rechnung. Ob Ihr Steuerberater ihn annimmt, entscheidet er.

Testnet. Nichts wird gespeichert: Name und Anschrift gehen nur an den bezahlten Abruf und werden nach der Antwort verworfen.

1. Anfrage

Zeitraum (nur abgeschlossene Tage, höchstens 92)
Was auf den Eigenbeleg kommt
Welche Dokumente (ein Preis, die CSV kommt immer mit)
Zahler (steht auf dem Eigenbeleg, geht nicht in die Vorschau)

3. Bezahlen und herunterladen

Zahlung per x402 auf NEAR: Sie signieren genau eine USDC-Überweisung, die API reicht sie ein und zahlt das Gas. Unterstützt: Meteor, Intear.

Datenschutz: Erst wenn Sie auf „Wallet verbinden“ klicken, lädt Ihr Browser den Code der Wallet, die Sie dann wählen, von deren Anbieter – Meteor von raw.githubusercontent.com (GitHub), Intear von wallet.intear.tech – und führt ihn abgeschottet in einem eingebetteten Rahmen aus. Dabei sehen GitHub bzw. der Wallet-Anbieter Ihre IP-Adresse; zum Signieren kann die Wallet ihre eigene Seite öffnen (wallet.meteorwallet.app bzw. wallet.intear.tech) und erfährt Ihr NEAR-Konto und die Zahlung, die Sie signieren. Vorher lädt diese Seite keinen fremden Code. Name und Anschrift gehen nur an diese API und nie an die Wallet.
