LE SPACEeigenbeleg

Eigenbeleg für Blockchain-Zahlungen

Kostenlos und quelloffen. Alles in Ihrem Browser, nichts auf unseren Servern.

Ein Eigenbeleg ist ein Beleg, den Sie selbst für Ihre eigenen Zahlungen ausstellen, wenn niemand eine Rechnung schickt: Netzwerkgebühren, Storage-Deposits, Zahlungen an Peer-to-Peer-Netzwerke. Er ist keine Rechnung. Ob Ihr Steuerberater ihn annimmt, entscheidet er.

Für alle, die auf NEAR, Akash oder Filecoin bezahlen, für Hosting, Speicher oder Verträge, und dafür einen Beleg für die Buchhaltung brauchen.

Die Seite liest die Chain, holt die Kurse und erstellt die PDFs in diesem Browser. Name und Anschrift verlassen das Gerät nie, und kein Server von uns sieht Ihre Adressen. Der Quellcode ist offen (AGPL-3.0), jeder kann prüfen, was die Seite tut.

Welche Dienste Ihr Browser dabei fragt

Ihr Browser fragt nur diese Dienste, direkt.

    Die Seite lässt sich als App installieren (im Browser-Menü „Installieren“ oder „Zum Home-Bildschirm“) und startet dann auch ohne Netz.

    1. Angaben

    Zeitraum (nur abgeschlossene Tage, höchstens 92)
    Was auf den Eigenbeleg kommt
    Welche Dokumente (die CSV kommt immer mit)
    Aussteller (steht auf dem Eigenbeleg, bleibt in diesem Browser)

    2. Ergebnis

    Drucken, prüfen und unterschreiben: Ein Eigenbeleg gilt erst mit Ihrer Unterschrift.

    Für Agenten: dieselben Dokumente per API, bezahlt per x402

    Wer einen Agenten für sich arbeiten lässt, nutzt die API. Sie prüft die Anfrage, liest, bewertet und zeichnet mit demselben Code wie diese Seite. Der Agent zahlt je Anfrage 0,10 USDC per x402, ohne Gas (derzeit auf dem NEAR-Testnet). Die Vorschau ist kostenlos, und abgebucht wird nur, wenn die Chain gelesen werden konnte.

    So beauftragen Sie zum Beispiel Claude oder einen anderen Agenten, der x402 kann:

    Besorge mir die Eigenbelege für Oktober 2026 für meine NEAR-Adresse wolkenfabrik.near von https://eigenbeleg.le-space.de. Lies zuerst https://eigenbeleg.le-space.de/llms.txt. Aussteller: Wolkenfabrik Hosting GmbH, Musterstraße 1, 12345 Beispielstadt. Zahle höchstens 0,10 USDC.

    Was die API ist, was sie kostet und wie man zahlt, sagt sie selbst:

    curl https://eigenbeleg.le-space.de/
curl https://eigenbeleg.le-space.de/llms.txt

    Der Agent aus dem Quellcode kauft innerhalb seines Budgets, prüft die PDFs und legt eine Quittung ab. Beauftragen lässt er sich auch auf dem NEAR AI Agent Market.
