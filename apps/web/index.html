Eigenbeleg für Blockchain-Zahlungen

Kostenlos und quelloffen. Alles in Ihrem Browser, nichts auf unseren Servern.

Ein Eigenbeleg ist ein Beleg, den Sie selbst für Ihre eigenen Zahlungen ausstellen, wenn niemand eine Rechnung schickt: Netzwerkgebühren, Storage-Deposits, Zahlungen an Peer-to-Peer-Netzwerke. Er ist keine Rechnung. Ob Ihr Steuerberater ihn annimmt, entscheidet er.

  4. Ergebnis

So geht's

Für alle, die auf NEAR, Akash oder Filecoin bezahlen, für Hosting, Speicher oder Verträge, und dafür einen Beleg für die Buchhaltung brauchen.

Die Seite liest die Chain, holt die Kurse und erstellt die PDFs in diesem Browser. Name und Anschrift verlassen das Gerät nie, und kein Server von uns sieht Ihre Adressen. Der Quellcode ist offen (AGPL-3.0), jeder kann prüfen, was die Seite tut.

Welche Dienste Ihr Browser dabei fragt

Ihr Browser fragt nur diese Dienste, direkt.

    Die Seite lässt sich als App installieren (im Browser-Menü „Installieren“ oder „Zum Home-Bildschirm“) und startet dann auch ohne Netz.

    Für Agenten: dieselben Dokumente per API, bezahlt per x402

    Wer einen Agenten für sich arbeiten lässt, nutzt die API. Sie prüft die Anfrage, liest, bewertet und zeichnet mit demselben Code wie diese Seite. Der Agent zahlt je Anfrage in USDC per x402, ohne Gas, auf NEAR, Base oder Ethereum. Die Vorschau ist kostenlos, und abgebucht wird nur, wenn die Chain gelesen werden konnte. Auf Wunsch schickt die API die Dateien zusätzlich per E-Mail, etwa an das Postfach eines Dokumentenmanagementsystems.

    Womit Agenten zahlen

    NetzAssetWiePreis je Anfrage
    NEAR near:mainnetUSDC (NEP-141)Eine signierte Delegate-Action; unser Relayer trägt das Gas0,10 USDC
    Base eip155:8453USDCEine signierte EIP-3009-Überweisung; unser Relayer trägt das Gas0,10 USDC
    Ethereum eip155:1USDCWie Base; teurer, weil das Gas auf Ethereum ein Vielfaches kostet1,00 USDC

    Die 402-Antwort bietet alle Netze an, der Agent wählt eins. Welche Netze und Preise die laufende API gerade annimmt, sagt sie selbst unter /llms.txt; der Hackathon-Stand läuft noch auf dem NEAR-Testnet.

    So beauftragen Sie zum Beispiel Claude oder einen anderen Agenten, der x402 kann (die Adresse ist unser eigener Testnet-Agent, mit echten Zahlungen):

    Besorge mir die Eigenbelege und den Kontoauszug für den 1. bis 6. November 2026 für meine NEAR-Testnet-Adresse eigenbeleg-agent.testnet von https://eigenbeleg.le-space.de. Lies zuerst https://eigenbeleg.le-space.de/llms.txt. Aussteller: Wolkenfabrik Hosting GmbH, Musterstraße 1, 12345 Beispielstadt. Zahle höchstens 0,10 USDC.

    Was die API ist, was sie kostet und wie man zahlt, sagt sie selbst:

    curl https://eigenbeleg.le-space.de/
curl https://eigenbeleg.le-space.de/llms.txt

    Der Agent aus dem Quellcode kauft innerhalb seines Budgets, prüft die PDFs und legt eine Quittung ab. Beauftragen lässt er sich auch auf dem NEAR AI Agent Market.
