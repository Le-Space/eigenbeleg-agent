Eigenbeleg für Blockchain-Zahlungen

Kostenlos und quelloffen. Alles in Ihrem Browser, nichts auf unseren Servern.

Ein Eigenbeleg ist ein Beleg, den Sie selbst für Ihre eigenen Zahlungen ausstellen, wenn niemand eine Rechnung schickt: Netzwerkgebühren, Storage-Deposits, Zahlungen an Peer-to-Peer-Netzwerke. Er ist keine Rechnung. Ob Ihr Steuerberater ihn annimmt, entscheidet er.

  4. Ergebnis

Ethereum und Base: mit Ihrem eigenen Alchemy-Schlüssel

Ethereum und Base liest die Seite über Alchemy, und das geht nur mit einem Schlüssel. Legen Sie sich einen kostenlosen Account bei alchemy.com an und tragen Sie den Schlüssel hier ein: Er geht von Ihrem Browser nur an Alchemy, nie an uns. Alchemy sieht dabei Ihre IP-Adresse, die Adressen und Ihren Schlüssel. Ohne Schlüssel bleiben die beiden Blockchains in der Liste ausgegraut. Tipp: Tragen Sie im Alchemy-Dashboard eigenbeleg.le-space.de als erlaubte Domain des Schlüssels ein, dann nützt er niemand anderem.

NEAR: eigener NearBlocks-Schlüssel (optional)

Ein Monat mit sehr vielen Transaktionen kann das kostenlose Limit von NearBlocks je IP-Adresse überschreiten; die Seite meldet das dann. Mit Ihrem eigenen Schlüssel von nearblocks.io gilt Ihr Limit. Er geht von Ihrem Browser nur an NearBlocks, nie an uns.

Ihre Blockchain fehlt? Ein Pull Request ist willkommen, wie steht in CONTRIBUTING.md, oder schreiben Sie an eigenbeleg@le-space.de.

    Für Agenten: dieselben Dokumente per API, bezahlt per x402

    Wer einen Agenten für sich arbeiten lässt, nutzt die API. Sie prüft die Anfrage, liest, bewertet und zeichnet mit demselben Code wie diese Seite. Der Agent zahlt je Anfrage in USDC per x402, ohne Gas, auf NEAR, Base oder Ethereum. Die Vorschau ist kostenlos, und abgebucht wird nur, wenn die Chain gelesen werden konnte. Auf Wunsch schickt die API die Dateien zusätzlich per E-Mail, etwa an das Postfach eines Dokumentenmanagementsystems.

    Womit Agenten zahlen

    NetzAssetWiePreis je Anfrage
    NEAR near:mainnetUSDC (NEP-141)Eine signierte Delegate-Action; unser Relayer trägt das Gas0,10 USDC (rund 0,09 €)
    Base eip155:8453USDCEine signierte EIP-3009-Überweisung; unser Relayer trägt das Gas0,10 USDC (rund 0,09 €)
    Ethereum eip155:1USDCWie Base; teurer, weil das Gas auf Ethereum ein Vielfaches kostet1,00 USDC (rund 0,90 €)

    Die 402-Antwort bietet alle Netze an, der Agent wählt eins. Bezahlt wird nur auf dem Mainnet, mit echtem USDC; die laufende API nennt die Preise auch unter /llms.txt. Alle Preise inkl. 19 % USt; 1 USDC ist an den US-Dollar gebunden, der Euro-Betrag ist ein Richtwert zum EZB-Kurs vom 13.11.2026. Rechnung auf Anforderung.

    Die bezahlte API ist nur für Unternehmer (§ 14 BGB), zu unseren AGB. Privatpersonen erstellen dieselben Dokumente kostenlos auf dieser Seite.

    Wer die Kontoauszüge jeden Monat braucht, abonniert sie: einmal zahlen, und ab dem 2. jedes Monats kommt der Auszug für den Vormonat per E-Mail, etwa ins Postfach des Dokumentenmanagementsystems. Ein Jahr auf einmal (1,20 USDC, auf Ethereum 12,00 USDC), oder 1 bis 12 Monate im Voraus zum normalen Preis je Anfrage (POST /eigenbeleg/subscribe/<Monate>). Dafür hebt die API Chain, Adressen, Aussteller (mit Logo, wenn eines mitgeschickt wurde) und E-Mail-Adresse verschlüsselt auf, bis der letzte Auszug verschickt ist oder Sie über den Link in jeder Mail beenden; Restmonate werden nicht erstattet. Ob die laufende API das Abo anbietet, steht in /llms.txt.

    So beauftragen Sie zum Beispiel Claude oder einen anderen Agenten, der x402 kann; Zeitraum, Adresse und Aussteller sind Beispiele, setzen Sie Ihre ein:

Lies zuerst https://eigenbeleg.le-space.de/llms.txt und zeig mir die kostenlose Vorschau, bevor du zahlst. Aussteller: Wolkenfabrik Hosting GmbH, Musterstraße 1, 12345 Beispielstadt. Zahle höchstens 0,10 USDC.

    Was die API ist, was sie kostet und wie man zahlt, sagt sie selbst:

    curl https://eigenbeleg.le-space.de/
curl https://eigenbeleg.le-space.de/llms.txt

    5. Storage in your browser

    The page keeps in your browser: the language (only when you click the switch), name, postal address and your logo, chain, network and addresses, and your Alchemy and NearBlocks keys (each only when you tick its "remember on this device"; unticking deletes them) and its own files in the service worker's cache, so the app starts without a network. None of it leaves your device (Sect. 25(2) no. 2 TDDDG); you can delete it at any time through your browser's site data. We set no cookies.

    6. The API for agents

    Whoever uses the API instead of the page sends blockchain addresses, the period, and the issuer's name and postal address – and the issuer's logo, if it is to be on the documents – to our server. They are used for that one answer only, neither stored nor logged (Art. 6(1)(b) GDPR). One exception: a logo sent with the API's free preview is stored by us, encrypted, for 24 hours, so that the order that follows need not send it again; it is deleted automatically afterwards. Whoever wants the files by e-mail as well gives an e-mail address; it is used for that one mail and not stored. The mail passes through our mail server, which logs the delivery as any mail server does. The payment is a transaction on the chosen blockchain (NEAR, Base or Ethereum) and public there, with the paying address. To execute it, our server sends the signed payment to a node of that network (NEAR: FastNEAR; Base and Ethereum: Alchemy or a public node). For our bookkeeping we record, per payment, the transaction hash, network, amount and date and keep them for ten years (§ 147 AO, § 257 HGB; Art. 6(1)(c) GDPR); name and postal address are not part of it unless you ask for an invoice. Whoever takes out a subscription of the API (twelve monthly statements by e-mail, paid once) has their blockchain addresses, name, postal address, logo (if one was sent), e-mail address and settings stored by us, encrypted, until the last statement or the cancellation through the link in every mail; they are deleted afterwards (Art. 6(1)(b) GDPR).
